# mp3fy

`mp3fy` will be a mobile application for turning supported media into MP3 audio in a simple, focused workflow.

This repository is intentionally starting as an empty product foundation. The product scope, supported sources, processing approach, and user experience will be defined before functionality is implemented.

## Initial principles

- Mobile-first experience
- Clear, lightweight interface
- Respect for copyright, permissions, and applicable laws
- Privacy-conscious handling of user-provided media
