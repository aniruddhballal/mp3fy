# mp3fy

`mp3fy` is a mobile application concept for converting supported media into MP3 audio through a simple, focused workflow.

The project is currently at the foundation stage. Product requirements, supported media sources, processing architecture, and the user experience will be defined before implementation begins.

## Current status

This repository contains only the initial Expo mobile-app scaffold. No conversion, download, upload, playback, or other product functionality has been implemented yet.

## Technology

- Expo
- React Native
- TypeScript

## Getting started

Install dependencies and start the Expo development server:

```bash
npm install
npm start
```

The app can then be opened in an Android emulator, iOS simulator, or the Expo Go app.

## Product considerations

Future design and implementation will account for user privacy, responsible media handling, copyright, and applicable laws.
